## Decisions and trade-offs

- **CSP allows inline scripts** (`'unsafe-inline'`). A nonce-based CSP would make every page render dynamically. The app never renders raw HTML, and every other directive is locked down. Revisit with Next's experimental SRI hashes when it is stable.
- **The `private` schema is not exposed** through the API (`config.toml`: `schemas = ["public", "graphql_public"]`). Anon has USAGE on it only so RLS policies can call the helpers.
- **Admin reads aren't audit-logged**, only changes are. Add read logging if support staff are hired.

## Findings fixed in this review

1. Supabase's default grants let `anon` INSERT, UPDATE, DELETE and TRUNCATE every public table. RLS blocked the row writes; TRUNCATE is not row-level. No API path could issue it, but it is now revoked (and for future tables).
2. Three foreign keys had no index (`payments.recorded_by`, `payments.refunded_by`, `business_payment_details.updated_by`).
3. Review reports had no rate limit.
4. The business page shipped Zod (~88 KB gzip) to the browser through a shared import. Fixed, and the bundle check now fails if Zod reaches the browser again.

## Open items (need the product owner)

- **SMS (Arkesel).** Integrated; the key goes in the `api-key` header (never a URL) and is covered by `pnpm check:secrets`. Use a dedicated key with an SMS limit, and reset any key that has appeared in a chat or screenshot.
- **Legal pages.** Privacy notice and terms (Act 843), written or reviewed by a lawyer. Consents are already recorded by version.
- **Hosted Supabase settings.** Leaked-password protection, SMS OTP expiry, and per-hour SMS cap: see `docs/deployment.md`.

## How to re-check

```bash
pnpm lint && pnpm typecheck && pnpm test && pnpm test:db && pnpm test:integration
pnpm build && pnpm check:secrets          # no secrets, no Zod in the browser bundle
pnpm audit --prod                          # no high/critical
grep -rn dangerouslySetInnerHTML src       # expect nothing
curl -sI http://localhost:3000/ | grep -iE "content-security|x-frame|nosniff|referrer|permissions"
```
